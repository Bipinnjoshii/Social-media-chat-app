# Campus Connect — Frontend Client

The React-based frontend client for the **Campus Connect** social media platform.

## Available Scripts

In the `client` directory, you can run:

### `npm start`
Runs the client application in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `npm run build`
Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for optimal performance.

### `npm test`
Launches the test runner in interactive watch mode.
